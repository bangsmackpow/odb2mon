Vehicle Communication Architecture & Protocol Stack

obd2mon is architected for low-latency vehicle interrogation using modern European OEM diagnostic standards:

ISO 13400 (DoIP - Diagnostic over Internet Protocol)

High-speed vehicle communication over standard Ethernet. The diagnostic tool establishes a TCP socket connection to the vehicle Central Gateway Module (ZGW at 169.254.1.1:6801). Handshake requires sending a Routing Activation Request (0x0005) with source tester address 0x0E00 before dispatching diagnostic messages.

ISO 14229 (UDS - Unified Diagnostic Services)

Standardized diagnostic service layer running over DoIP frames. Supports:

  • Service 0x10: Diagnostic Session Control (Default Session 0x01, Extended Diagnostic Session 0x03).
  • Service 0x22: Read Data By Identifier (DID) for manufacturer engineering telemetry.
  • Service 0x2E: Write Data By Identifier (DID) for FDL feature coding and memory parameter configuration.
  • Service 0x11: ECU Reset (Soft Reset 0x03) to immediately apply written coding parameters without power cycling.
  • Service 0x31: Routine Control (Start 0x01, Stop 0x02, Request Results 0x03).
  • Service 0x19: Read DTC Information by status availability mask (0x02 0xFF).
  • Service 0x04: Clear Diagnostic Information across all vehicle domains (0xFFFFFF).

SAE J1979 / ELM327 (Emissions OBD2)

Standardized North American emissions protocol communicating via serial/Bluetooth interface (default COM3, 38400 baud). Mode 01 requests live current sensor PIDs; Mode 03 fetches confirmed DTCs.

Diagnostic Trouble Codes & Status Masks

Fault codes are interrogated using UDS Service 0x19 0x02 0xFF across all electronic controllers.

Status Byte Bitmask Breakdown

  • Bit 3 (0x08) - Confirmed DTC: The fault has been verified during multiple driving cycles and logged permanently.
  • Bit 2 (0x04) - Pending DTC: Fault was detected during the current or previous drive cycle but requires further cycle confirmation.
  • Bit 0 (0x01) - Test Failed: The diagnostic check failed during the current test execution.

Clearing Fault Memory

Executing clear fault codes dispatches Service 0x04 0xFF 0xFF 0xFF. This erases freeze frames, resets state emissions readiness monitors, and restores fault memory.

ECU Network Topology (ISTA+ Tree View)

Multi-bus controller scan querying 16 distinct Electronic Control Units across 4 vehicle bus architectures:

  • PT-CAN (Powertrain, 500 kbps): DME (Engine), EGS (Transmission), DSC (Brakes/ABS), EKPS (Fuel Pump), GWS (Gear Selector).
  • FlexRay (Chassis, 10 Mbps): EPS (Electric Steering), ICM (Chassis Mgmt), EMF (Parking Brake).
  • K-CAN (Body, 100 kbps): CAS (Immobilizer), KOMBI (Cluster), IHKA (Climate), FRM (Footwell), JBE (Junction Box), PDC (Parking).
  • Ethernet (Gateway, 100 Mbps): ZGW (Central Gateway), HU_NBT (Navigation / Infotainment).

Node Health States

Green (Normal): Responding normally with 0 DTCs.
Amber (Fault Stored): Responding normally but has 1 or more persistent fault codes in memory.
Red (Comm Error): Returned Negative Response Code (NRC) or transmission framing error.
Grey (No Response): Controller unequipped or failed to answer before timeout.

Intelligent Battery Sensor (IBS) & Power Management

BMW vehicles utilize a closed-loop micro-controller on the negative battery terminal to calculate state of charge, degradation, and internal resistance.

IBS Telemetry (DID 0xD010)

  • State of Charge (SoC %): Real-time usable energy percentage.
  • Terminal Voltage (mV): Operating voltage (Resting 12.6V, Alternator charging 14.2V - 14.7V).
  • Net Current (0.1A): Signed net current into (+) or out of (-) the battery.
  • Core Temperature (°C): Battery cell temperature.

Battery Registration (Routine 0x0219)

When installing a replacement battery, the DME must be informed via Routine 0x0219. This:

  1. Resets the alternator charging curve (as batteries age, the DME increases charging voltage; a new battery will boil and fail prematurely without registration).
  2. Clears internal aging histograms.
  3. Appends the current vehicle odometer into DME DID 0x2036 history.

Condition Based Service (CBS) Monitoring & Reset

Tracks consumable wear and inspection schedules based on driving habits, oil degradation algorithms, and brake pad wear sensors (DID 0xD020).

Service Item Target IDs

  • 0x01: Engine Oil (Tracks mileage and calendar interval).
  • 0x02: Front Brake Pads (Tracks two-stage pad wear sensor).
  • 0x03: Rear Brake Pads (Tracks rear axle brake wear).
  • 0x04: Brake Fluid (2-year mandatory moisture interval).
  • 0x05: Vehicle Check / Statutory Inspection.

Executing Routine 0x0220 with the specific target item ID resets its remaining life to 100% and advances the inspection calendar.

BMW Actuator Service Routines

Direct component test actuations and maintenance procedures:

Electric Water Pump Bleed (Routine 0x0211)

Purges trapped air pockets from the N55 cooling system after coolant changes or pump replacement. Runs an automated 12-minute cycle with 4 pulse stages (15% -> 50% -> 85% -> 100%).

Prerequisites: Ignition ON, Engine OFF, coolant reservoir sealed, battery maintainer connected, heater set to 84°F with lowest fan.

ZF 8HP Transmission Fluid Temperature (DID 0x2045 & Routine 0x0225)

Automatic transmission fluid level must be checked only when the sump oil temperature is between 40°C and 50°C. Routine 0x0225 commands the EGS to hold torque converter fill RPM during inspection.

Radiator Cooling Fan Test (Routine 0x0215)

Commands the variable-speed electric cooling fan to 15% (Low), 50% (Medium), 90% (High), or restores DME automatic control (0%).

Exhaust Flap Actuator (Routine 0x0218)

Forces the muffler flapper valve open (sport sound) or closed (quiet mode).

BMW N55 High-Speed Datalogging & Advanced Engine Diagnostics

Provides high-frequency (20 - 50 Hz) interrogation of Bosch MEVD1726 DME internal engineering registers over ENET (ISO 13400 DoIP / ISO 14229 UDS DID 0xD100). Eliminates the bandwidth bottlenecks and PID latency of generic SAE J1979 emissions OBD-II.

Turbocharger & Boost Control

  • Target Boost (hPa / psi): The DME's dynamic charge pressure calculation based on driver torque demand, ambient pressure, charge air temperature, and knock adaptation.
  • Actual Boost (hPa / psi): Charge pipe absolute pressure measured by the TMAP sensor ahead of the throttle valve.
  • Wastegate Duty Cycle (WGDC %): Commanded pneumatic wastegate solenoid duty (PWG on 2011 F10) or electronic wastegate actuator position (EWG on late N55). During initial spool, WGDC approaches 80 - 85%; during sustained boost, it modulates between 55% - 70%.

Fuel Delivery Telemetry

  • HPFP Rail Pressure (Target vs Actual, bar): Direct injection rail pressure. Normal idle: ~50 bar (725 psi). Wide-open throttle (WOT): 150 - 200 bar (2,175 - 2,900 psi). A pressure drop below 130 bar during high RPM pull indicates a weakening High Pressure Fuel Pump.
  • LPFP Feed Pressure (bar): Tank delivery pump pressure feeding the engine bay HPFP. Normal range: 5.0 - 5.5 bar. Drops below 4.5 bar signify in-tank pump or fuel filter restriction.
  • Lambda (λ) / Air-Fuel Ratio: Measured by the upstream wideband oxygen sensor. Normal cruising: 1.00 λ (14.7 AFR). WOT acceleration: 0.82 - 0.88 λ (12.0 - 13.0 AFR).

Combustion Health & Knock Adaptation

  • Individual Cylinder Knock Retard (° CRK): Real-time ignition timing retard per cylinder (Cyl 1 - 6) triggered by the dual block-mounted knock sensors. Zero degrees indicates optimal timing; corrections between -1.0° and -3.0° indicate minor fuel octane deficiency or elevated intake air temperatures; corrections greater than -3.0° suggest pre-ignition risk.
  • Individual Cylinder Misfire Counters: Cumulative combustion misfire events recorded per cylinder since ignition cycle start. Crucial for pinpointing weak ignition coils, fouled spark plugs, or leaking direct injectors.
  • VANOS Camshaft Timing (° CRK): Target vs Actual angular phasing for Intake and Exhaust camshafts. Target tracking within ±1.5° CRK confirms healthy VANOS solenoids and non-sticking camshaft central valves.

BMW FDL Coding & Vehicle Customizations

FDL (Funktionsdatenlese) coding allows users to configure and personalize factory features across electronic control units over standard ISO 14229 UDS diagnostic services.

Diagnostic Architecture & Services

  • Read Parameters: Queries non-volatile memory configuration blocks using UDS Service 0x22 (Read Data By Identifier).
  • Write Parameters: Elevates communication to Extended Diagnostic Session (0x10 0x03) and updates the target byte/bitmask with Service 0x2E (Write Data By Identifier).
  • Module Reload: Dispatches UDS Service 0x11 0x03 (ECU Soft Reset) to command the target controller to apply the newly written configuration immediately.

Configurable Systems & ECUs

  • KOMBI (Instrument Cluster, 0x0060): Warning Gong tone (BMW Standard, Rolls-Royce, BMW i, Mini), Digital speedometer in center cluster display.
  • CAS (Car Access System, 0x0040): Seat belt warning chime disable, Comfort Access instant auto-folding mirrors on lock, Auto-unlock doors on engine stop, Auto Start/Stop memory.
  • FRM (Footwell Module, 0x0072): Welcome lights duration (10s–60s), Pathway follow-me-home headlights timing (30s–120s), Comfort turn signals (1, 3, or 5 blinks), Angel eye halo ring brightness with low beams (8%, 12%, 50%, 100%), Fog lights on with high beams.
  • HU_NBT (iDrive Headunit, 0x0063): Startup legal disclaimer removal / instant boot.

Safety Protocols & Automated Backups

Prior to executing any write command, obd2mon captures a snapshot of the target DID block to disk under vehicles/<vehicle_id>/coding_backups/. If any unexpected behavior occurs, you can one-click restore any previous state from the BACKUPS & RESTORE modal. Furthermore, the Intelligent Battery Sensor (DID 0xD010) guards against programming if battery voltage drops below 12.0V.

BMW ENET Cable (RJ45-to-OBD2)

  • Ignition: Ensure vehicle ignition is in Terminal 15 (KL15 - ignition ON, engine not running).
